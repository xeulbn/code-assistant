# Apple 기업 분석

추가 설치 없이 실행하는 한 장의 웹 페이지입니다. 외부 라이브러리나 실시간 API를 사용하지 않습니다.

프로젝트 루트에서 실행:

```sh
python3 -m http.server 8112 --bind 127.0.0.1 --directory example1125
```

브라우저에서 http://127.0.0.1:8112 를 엽니다. `index.html`을 직접 열어도 동작합니다.

프로젝트 루트에서 검사:

```sh
python3 example1125/check.py
```

검사는 Python 표준 라이브러리로 파일·출처 연결·재무 합계·가격 날짜와 데이터 형식을 확인하고, 임시 로컬 서버로 페이지와 자산의 응답을 확인합니다. Node.js가 있으면 JavaScript 문법도 확인합니다. 브라우저 상호작용 검사는 포함하지 않습니다.

재무는 2026.09.26 결산, 주가는 2026.11.24 미국 정규장 종가까지입니다. 수치는 `data.js`, 출처와 작성 시점은 페이지 하단에 있습니다. 주가 차트의 가로축은 거래일 순서이며, 기간 첫 종가 대비 변화율을 표시합니다. 자동 갱신하지 않습니다.
