## 공통 규칙

- 실행 명령 하나를 반드시 제공한다.
- 검사 명령 하나를 반드시 제공한다.
- 결과물은 브라우저에서 열려야 한다.
- 추가 설치 없이 지금 환경에서 바로 실행되어야 한다.
- 작업 시작 전에 선택한 언어·도구와 선택 이유를 한 줄로 알린다.
- 검색하면 바로 나오는 일반 정보나 기준표 대신 지금 이 경우의 답만 보여준다.
- 답변은 한국어로 한다.

## 이 프로젝트 규칙

- 회사 하나를 분석하는 웹 페이지를 개요, 재무 요약, 최근 뉴스, 리스크 네 부분으로 구성한다.
- 투자 판단에 쓰라고 권하는 문구를 넣지 않는다.
- 빠진 자료는 블록 하나에 무엇이 없는지, 왜 없는지, 판단에 어떤 영향을 주는지 적는다.
- 재무 요약에는 가격 변동 차트를 넣고 기간을 함께 적는다.
- 본문에는 출처 번호만 달고, 페이지 맨 아래 출처 목록에 번호별로 모은다.
- 작성 시점과 자료 기준일은 페이지 맨 아래 출처 목록 옆에 한 줄로 둔다.
